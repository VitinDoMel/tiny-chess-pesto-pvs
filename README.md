Deterministic 0x88 chess engine compressed from Python source into 4,080 bytes with PeSTO MG/EG PSTs, pawn/rook/king eval, mop-up, PVS, TT, null-move, LMR, LMP, RFP, and check extensions.

## Run it

```sh
python3 -P -s main.py
```
